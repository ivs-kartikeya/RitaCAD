# Start modeling with RitaCAD

1. Extract the Windows portable ZIP with **Extract All**.
2. Open the extracted **RitaCAD** folder and double-click **RitaCAD.exe**.
3. Choose **File → Open** and pick an editable `.ritacad` file under `samples/evolve` or `samples/v05`.

RitaCAD uses Windows x64, .NET Framework 4.8 and OpenGL supplied by Windows and your display driver. The portable package includes the application, native examples and guides. When reporting launch trouble, include your Windows version, the executable version and the exact error. [Microsoft .NET Framework guidance](https://learn.microsoft.com/en-us/dotnet/framework/install/on-windows-10)

The tree on the left shows native features. Select one to inspect or edit its properties. Double-click an editable sketch to resume sketching. Start a sketch on a selected planar face or an origin plane. Finish the sketch, then choose Extrude and review the closed region and depth. Save the native project to keep its editable features.

| Interaction | Input |
| --- | --- |
| Pan | Middle button drag |
| Orbit | Shift + middle button drag |
| Zoom | Mouse wheel |
| Select face or body | Click face or double-click for its body |
| Move selection | M, then drag an axis or enter a distance |
| Fit model or active sketch | F |
| Fit selection | Shift+F |
| Search commands | Ctrl+K |
| Open RitaAI | Ctrl+Shift+A |
| Undo / Redo | Ctrl+Z / Ctrl+Y |

Use the right-side workspace to switch between Properties and RitaAI. In Designer enter a supported brief and review the validated preview before approval. Use File → Save for the editable result. Copilot reads the selected feature or geometry. Teacher provides authored exercises and checks the document or answers against each objective.
