# Known limits

RitaCAD 0.6 RC1 is a Windows release candidate. Supported native modeling includes editable sketches, analytic extrusion and revolve, bounded planar joins and pockets, and eligible prism/axis bores. Feature availability depends on the selected geometry and the operation domain shown in the interface.

Designer supports bounded part recipes and reviewed native edits. Bent sheet metal, arbitrary assemblies, general solid Booleans, arbitrary selected-edge blends, STEP interchange, FEA and general engineering chat remain outside this release. The L-shaped bracket example uses an explicit rectangular base and upright joined at a planar face. It represents a sharp solid bracket.

Teacher examples explain engineering drawings, dimensions, tolerances and datums. These are educational exercises. Compliance certification and tolerance-stack solving require separate engineering verification.

Compatibility evidence is from the tested Windows machine. CPU-only inference on a modern host configured with four threads is a simulation of CPU availability. Real 8 GB hardware, integrated graphics, physical multi-monitor DPI switching and system-wide network isolation remain unverified.
